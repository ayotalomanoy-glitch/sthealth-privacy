# Privacy Policy for Sthealth Stretch

**Last Updated: June 2, 2026**

## 1. Data Collection and Usage
Sthealth Stretch operates entirely locally on your device. We respect your privacy and **do not collect, store, track, or transmit any personal data, telemetry, or usage statistics.**

## 2. Core Functionality
The application utilizes the local Windows API (`GetLastInputInfo`) strictly to monitor idle time for timer functionality. This process occurs in real-time within your device's memory. No input data or keystrokes are recorded, saved, or sent to any external servers.

## 3. Contact
If you have any questions or concerns regarding this policy, please open an issue on our GitHub repository.
